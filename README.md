# Contador de cédulas disponíveis

Calculadora de saque que informa a quantidade de cédulas de R$ 100, R$ 50, R$ 20 e R$ 10 necessárias para compor o valor informado. Exercício de estudo de lógica e JavaScript.

## Stack
- HTML, CSS, JavaScript e Bootstrap 5

## Como executar
Abra `index.html` no navegador. Demo: https://52rmqb.csb.app/.
